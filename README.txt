# Garufa Parrilla Argentina — Experiencia 360°

Demo de experiencia visual interactiva desarrollada por **ViewmetricaMX | Reality Intelligence** para Garufa Parrilla Argentina, Torreón.

El proyecto permite explorar diferentes áreas del restaurante mediante fotografía 360°, navegación interactiva y una presentación visual orientada a la experiencia del cliente.

## Tecnología

- HTML5
- CSS3
- JavaScript
- Three.js
- Fotografía 360°
- Diseño responsive
